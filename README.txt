MAKNETIZA ACADEMY — LANDING PAGE DE AFILIADO

ARCHIVOS
- index.html: estructura y contenido.
- styles.css: diseño responsive para móvil, tablet y PC.
- script.js: HotLink, menú móvil, FAQ, animaciones y validación.
- assets/hero.webp: única imagen de fondo del proyecto.

PASO OBLIGATORIO ANTES DE PUBLICAR
1. Abre script.js.
2. Busca:
   const AFFILIATE_URL = 'TU_HOTLINK_DE_HOTMART_AQUI';
3. Pega tu HotLink de afiliado de Hotmart entre las comillas.
4. Guarda el archivo.

EJEMPLO
const AFFILIATE_URL = 'https://go.hotmart.com/TU-CODIGO';

IMPORTANTE
- No uses la URL normal del Marketplace como si fuera tu enlace de afiliado.
- Revisa precio, plan, disponibilidad y condiciones antes de publicar.
- Mantén visible la divulgación de afiliado y el aviso de no garantía de resultados.

PUBLICACIÓN
Puedes subir la carpeta completa a Netlify, Cloudflare Pages, GitHub Pages o cualquier hosting estático.
